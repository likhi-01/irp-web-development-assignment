
# IRP Web Development Assignment

## Project Overview

This project is developed as part of the Web Development Foundations Technical Practical Assignment.

It contains two parts:

### Part A: Responsive IRP LMS Homepage

- Developed using HTML5 and CSS3.
- Created a responsive navigation bar.
- Designed a hero section with an illustration.
- Created five Learning Journey cards.
- Used Flexbox, CSS Grid, and Media Queries.
- Supports desktop, tablet, and mobile screens.

### Part B: JavaScript Bank Simulator

- Implemented amount validation using parseAmount().
- Demonstrated type coercion.
- Used try-catch for error handling.
- Demonstrated var, let, and const.
- Explained hoisting and the Temporal Dead Zone.
- Compared asynchronous loops using var and let.

## How to Run

### Part A

1. Open part-a-responsive-ui/index.html.
2. Run it using the VS Code Live Server extension.
3. View the webpage in Google Chrome.

### Part B

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

node part-b-javascript/bank.js
